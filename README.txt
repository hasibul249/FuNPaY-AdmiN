FuNPaY Admin অ্যাপ v1.3
========================
এটা মূল FuNPaY অ্যাপের কন্ট্রোল প্যানেল: KYC যাচাই (NID ও মুখের ছবি দেখে একসেপ্ট/বাতিল), ইউজার সাসপেন্ড/বন্ধ, ব্যানার, নোটিশ, কুপন, রক্ষণাবেক্ষণ মোড, লেনদেন দেখা, অডিট লগ।
ভবিষ্যতের মার্চেন্ট ও এজেন্ট অ্যাপও একই ডাটাবেসে যুক্ত হবে (profiles.role = user / agent / merchant)।

ধাপ ১) ডাটাবেস (একবারই)
-----------------------
১) মূল অ্যাপ (v2.18) এর backend/update-v2.13.sql (এবং OTP চালু থাকলে update-otp.sql) আগে চালানো থাকতে হবে।
২) Supabase SQL Editor এ backend/update-v2.15.sql এর পুরোটা পেস্ট করে Run করুন।
৩) OTP চালু থাকলে প্রথমে SQL Editor এ এটা Run করুন (নইলে অ্যাডমিন ইউজার বানানো আটকাবে):
     alter table auth.users disable trigger a_require_verified_phone;
   তারপর Supabase > Authentication > Users > Add user: আপনার অ্যাডমিন ইমেইল ও পাসওয়ার্ড দিন, "Auto Confirm User" টিক দিন।
   তারপর সঙ্গে সঙ্গে এটা Run করে নিয়মটা আবার চালু করুন (ভুলবেন না):
     alter table auth.users enable trigger a_require_verified_phone;
   (নতুন স্টাফ অ্যাডমিন বানানোর সময়ও একই নিয়ম।)
৪) SQL Editor এ নিজের ইমেইল বসিয়ে Run করুন:
     insert into public.admins(user_id, name, level)
     select id, 'আমি', 'owner' from auth.users where email = 'আপনার@ইমেইল.com';
   (এটা সাধারণ ইউজার অ্যাকাউন্ট নয়, তাই মূল অ্যাপে এই ইমেইল দিয়ে লগইন হবে না। ভালো কথা।)
৫) KYC এর জন্য (জরুরি): মূল অ্যাপের backend/update-v2.18-kyc.sql (এই zip এর backend ফোল্ডারেও আছে) Supabase SQL Editor এ পুরোটা Run করুন। আবার চালালেও সমস্যা নেই।
   এতে মূল অ্যাপের v2.17 (KYC) এর কাজও আছে, তাই update-v2.17.sql আলাদা চালাবেন না। এটা অ্যাডমিন ও ইউজার অ্যাপের "notices" ও "admins" টেবিলের গরমিল মিলিয়ে দেয়।
   ক্রম: update-v2.13 (ও update-otp) > update-v2.15 > update-v2.18-kyc। এটা না চালালে KYC ট্যাব "ডাটাবেস আপডেট বাকি" দেখাবে।
৫খ) (v1.3, মুখ মেলানো) backend/update-v2.20-kyc-auto.sql ও Run করুন (v2.18 এর পরে)। এতে ইউজার অ্যাপে ৮৫% মিলে অটো একসেপ্ট চালু হয় এবং এই অ্যাডমিন অ্যাপে মিল %, লাইভনেস, কারণ-চিহ্ন (flags), "অটো" তালিকা ও "অটো একসেপ্ট বাতিল" বাটন যোগ হয়। না চালালে KYC ট্যাব আগের মতোই কাজ করে কিন্তু মিল % দেখাবে না।
৬) (ইচ্ছা হলে) ইউজারকে SMS ও নতুন আবেদনে Telegram এ খবর যাওয়ার জন্য মূল অ্যাপের KYC-ADMIN-SETUP.txt এর "ঘ" ধাপে kyc-notify ফাংশন Deploy করুন।

ধাপ ২) অ্যাপ বানানো (মূল অ্যাপের মতোই)
--------------------------------------
আলাদা নতুন GitHub repository বানান (যেমন funpay-admin)। এই zip টা সেখানে Upload করে Commit করুন।
Settings > Secrets and variables > Actions এ SUPA_URL ও SUPA_KEY (মূল অ্যাপের একই) বসান।
Actions এ বিল্ড শেষ হলে APK লিংক:
  https://raw.githubusercontent.com/আপনার-ইউজারনেম/রিপোর-নাম/apk/FuNPaY-Admin.apk
পিসিতে চালাতে: www/index.html ব্রাউজারে খুলুন, লগইন পেজে Supabase URL ও anon key একবার লিখুন।

ব্যবহার
-------
- KYC: নিচের "KYC" ট্যাবে বাকি আবেদনের তালিকা (নাম/নম্বর/NID দিয়ে খোঁজা যায়)। আবেদন খুললে NID সামনে-পেছনের ছবি, সেলফি ও পড়া তথ্য (নাম, পিতার নাম = নমিনি, জন্মতারিখ, NID, ঠিকানা) একসঙ্গে দেখা যায়। ছবিতে চাপ দিলে বড় হয়।
  একসেপ্ট করলে ইউজারের অ্যাকাউন্ট চালু হয় ও তার মেসেজ বক্সে নোটিশ যায়। বাতিল করতে কারণ লিখতে হয় ("ছবি অস্পষ্ট", "মুখ মেলেনি", "তথ্য পড়া যায়নি" বোতামও আছে), কারণটা ইউজার দেখে আবার জমা দিতে পারে।
  নতুন আবেদন এলে হোমের কার্ডে ও KYC ট্যাবের ব্যাজে সংখ্যা দেখায়। সব সিদ্ধান্ত অডিট লগে ওঠে। ইউজারের প্রোফাইলেও KYC অবস্থা দেখা যায়।
- হোম: আজকের হিসাব, ৭ দিনের চার্ট, রক্ষণাবেক্ষণ চালু/বন্ধ।
- ইউজার: খুঁজুন, স্থগিত/চালু/বন্ধ করুন, কুপন দিন, নোটিশ পাঠান, এজেন্ট/মার্চেন্ট বানান (শুধু মালিক)।
- কনটেন্ট: ব্যানার (প্রিভিউসহ), নোটিশ (সবাইকে/এক ধরনের/একজনকে, পপআপ), কুপন বানানো ও সবাইকে দেওয়া।
- রক্ষণাবেক্ষণ চালু করলে ১০ সেকেন্ডের মধ্যে সবার অ্যাপে সুন্দর বার্তা আসে ও সার্ভারেই সব লেনদেন বন্ধ হয়। শেষ করলে অ্যাপ নিজে খুলে যায়।
- মালিক ও স্টাফ: স্টাফ রক্ষণাবেক্ষণ, অ্যাকাউন্ট বন্ধ, ধরন বদল, অ্যাডমিন যোগ ও অডিট লগ করতে পারবে না।
নিরাপত্তা: অ্যাডমিনের ক্ষমতা সার্ভারে (Supabase) যাচাই হয়, অ্যাপ বদলালেও সাধারণ ইউজার কিছু করতে পারবে না। ৫ মিনিট ব্যাকগ্রাউন্ডে থাকলে নিজে লগআউট হয়।
দ্রষ্টব্য: অ্যাডমিন অ্যাপে OTA আপডেট নেই, বদলালে নতুন APK বানিয়ে ইনস্টল করতে হবে।

আপলোড করলে কী হয় + OTA আপডেট (v1.3)
------------------------------------
* রিপোতে এই zip টা Upload করে Commit করলেই GitHub নিজে আনজিপ করে দুটো কাজ করে:
    ১) OTA: ১-২ মিনিটে নতুন কোড "ota" শাখায় যায়। আগে ইনস্টল করা অ্যাডমিন অ্যাপ নিজে সেটা নামিয়ে নেয় (APK লাগে না)।
    ২) APK: নতুন APK বানায় (১০-২০ মিনিট)। শুধু প্রথমবার ইনস্টলের জন্য, বা নতুন নেটিভ ফিচার যোগ করলে।
* একবার এই v1.3 এর APK ইনস্টল করতে হবে (পুরনো APK তে OTA লোডার নেই)। তারপর থেকে শুধু আপলোড করলেই আপডেট চলে আসবে।
* অ্যাপ খোলার ২-৩ সেকেন্ড পরে, ফোনে ফিরে এলে, আর প্রতি ১০ মিনিটে নিজে নতুন আপডেট দেখে। "আরও" পাতায় "আপডেট চেক করুন" বাটনে হাতে দেখাও যায়।
* কাজের মাঝখানে (ফর্ম/ছবি/ডায়ালগ খোলা) রিলোড হয় না, ফাঁকা হলে নিজে বসে। নতুন কোড ভাঙা হলে অ্যাপ নিজে আগের ভার্সনে ফিরে যায়।
* Actions ট্যাবে "Build FuNPaY Admin" এ ota ও apk দুটো কাজই সবুজ হতে হবে। ota সবুজ হলেই আপডেট পাঠানো হয়ে গেছে।
* SQL বদলালে (যেমন update-v2.20) OTA তে যায় না, ওটা Supabase এ হাতে Run করতে হয়।
